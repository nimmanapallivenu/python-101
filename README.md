## 🎓 Java vs Python Quick Reference

| Concept | Java | Python |
|---------|------|--------|
| Variable Declaration | `String name = "John";` | `name = "John"` |
| Class Definition | `public class MyClass {}` | `class MyClass:` |
| Method Definition | `public void myMethod() {}` | `def my_method():` |
| List/Array | `List<String> list = new ArrayList<>();` | `list = []` |
| Dictionary/Map | `Map<String, Integer> map = new HashMap<>();` | `dict = {}` |
| Null | `null` | `None` |
| Boolean | `true/false` | `True/False` |
| String Concatenation | `"Hello " + name` | `f"Hello {name}"` |
| Exception Handling | `try-catch-finally` | `try-except-finally` |
| Inheritance | `extends` | `class Child(Parent):` |
